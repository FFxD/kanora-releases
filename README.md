# Kanora Releases

Installers for **Kanora**, a Windows app that records gaming sessions on Android handhelds over
USB or Wi-Fi (adb).

This repository contains **no source code**, only the installers under [Releases](../../releases).
Each release lists the SHA-256 hash of the installer. Kanora's built-in update check uses the files
published here.

- The installer is not code-signed yet, so Windows SmartScreen will warn. Please verify the
  SHA-256 hash before running it:
  `Get-FileHash "<path to installer>" -Algorithm SHA256`
